# D-001 - Game install folder is resolved from `appmanifest_784150.acf`, not hardcoded

- **Decided:** 2026-09-19 23:16

## Issue

`SPEC.md` §2.1 gives the game install folder as
`steamapps/common/Workers & Resources Soviet Republic/`, annotated "exact
folder name to be confirmed against a real install." This was open item #2
in `SPEC.md` §6, and it blocks `wrsrcli path --auto-detect` (Phase 1).

Checked against the real install on the dev machine. The spec's guess is
wrong — the actual directory is:

```
C:\Program Files (x86)\Steam\steamapps\common\SovietRepublic
```

The display name `Workers & Resources: Soviet Republic` does exist, but as
the `"name"` field inside `steamapps/appmanifest_784150.acf`, not as the
directory name. That same file also carries the directory name explicitly:

```
"name"          "Workers & Resources: Soviet Republic"
"installdir"    "SovietRepublic"
```

Tradeoffs considered:

1. **Hardcode `SovietRepublic`.** Simplest, and matches the "Simplicity
   first" rule in `AGENTS.md`. But it bakes in a value owned by Valve and
   the game's publisher. If the depot's `installdir` ever changes, or
   differs for a non-standard install, autodetect silently resolves to a
   path that does not exist.
2. **Read `installdir` from `appmanifest_784150.acf`.** Authoritative —
   it is the field Steam itself uses to place the install. Costs nothing
   extra in dependencies or complexity: Phase 1 already parses
   `libraryfolders.vdf` to enumerate library folders, and Phase 2 already
   builds an `.acf` parser for `appworkshop_784150.acf`. The app manifest
   sits in the same `steamapps/` directory being walked and uses the same
   format.
3. **Glob `steamapps/common/` for a likely match.** Rejected — fuzzy
   matching on directory names is guesswork with no authoritative anchor,
   and could match the wrong game.

Option 2 is not a speculative abstraction; it reuses machinery the plan
already requires and removes a hardcoded third-party value.

## Decision

Open item #2 is closed. `wrsrcli` resolves the game install folder by
reading the `installdir` key from `steamapps/appmanifest_784150.acf` in
whichever library folder holds app `784150`, then joining it to that
library's `steamapps/common/`.

- On this dev machine that resolves to
  `C:\Program Files (x86)\Steam\steamapps\common\SovietRepublic`, which is
  the value `path --auto-detect` must report for Phase 1's verify step.
- `SovietRepublic` is recorded here as the observed value for reference
  only. It must **not** be hardcoded as a fallback — if
  `appmanifest_784150.acf` is missing or has no `installdir`, autodetect
  fails and reports that, leaving the user to set the path explicitly with
  `wrsrcli path --game "{path}"` (per `SPEC.md` §3).
- `SPEC.md` §2.1 and §6 item 2 need updating to match; the §2.1 path is
  currently wrong as written.
