# D-006 - `output-table`'s "Filename" column is `$ITEM_NAME`

- **Decided:** 2026-09-19 23:41

## Issue

`SPEC.md` §4.2 lists the table columns as *"Item ID, Filename, Item Type
(category) / raw `$TAGS` values (subcategory), Author name (API mode) or
Owner ID (no-API mode), Posted date, Updated date, File size (API mode
only)"*.

Separately, the same section lists the data available in no-API mode as
*"Item ID, folder name, `$ITEM_NAME`, `$ITEM_TYPE`, `$TAGS` (raw values),
`$OWNER_ID` ... plus `.acf`-derived dates"*.

"Filename" appears in the column list but not the data list, and
`$ITEM_NAME` appears in the data list but not the column list, so the two
lists have to be reconciled.

Phase 2 verification established the deciding fact: **workshop folder
names are the item IDs.** All 20 items with a `workshopconfig.ini` had
`$ITEM_ID` equal to their containing folder's name. So a column showing
the folder name would be a character-for-character duplicate of the Item
ID column.

Tradeoffs considered:

1. **"Filename" means `$ITEM_NAME`.** Reconciles both lists: the one
   listed data field without a column maps to the one column without a
   data field. Gives the table the human-readable mod name, without which
   the output is 21 rows of opaque numeric IDs.
2. **"Filename" means the folder name, literally.** Faithful to the word,
   but produces a column identical to Item ID and leaves `$ITEM_NAME` —
   explicitly listed as available — rendered nowhere.
3. **Two columns, Name and Folder.** Keeps both. Rejected: the folder
   column is redundant with Item ID, and `AGENTS.md` favors the minimum
   that satisfies the spec.

## Decision

The column labelled "Filename" in `SPEC.md` §4.2 is the item's display
name from `$ITEM_NAME` in `workshopconfig.ini`. The rendered table labels
it **Name**, since "Filename" describes neither what it holds nor where it
comes from.

Where `workshopconfig.ini` is absent (decision D-005), the cell shows
`(no workshopconfig.ini)` rather than an empty cell, so the row's state is
legible in the table itself.

No separate folder column is rendered; the Item ID is the folder name.

`SPEC.md` §4.2's column list updated to say `Name (`$ITEM_NAME`)`.

## Superseded

Not superseded.
